## 🇪🇸 Español

### 📖 Sobre el proyecto
**Yag2Dpg** comenzó en mayo de 2026 como un simple ejercicio práctico para enseñar a programar a los alumnos de la asignatura TICO de 1º de Bachillerato del IES Campanillas. Sin embargo, el proyecto escaló rápidamente hasta convertirse en la base de un videojuego real. 

Actualmente, el proyecto se encuentra en su fase inicial, y la primera herramienta completamente funcional y pública es el **Editor de Niveles Web**.

### ✨ Características actuales
* **Editor de Niveles Web:** Interfaz moderna y *responsive* con soporte para capas (Fondo, Medio, Frente, Spawn, Meta).
* **Exportación en ZIP:** El editor empaqueta automáticamente el mapa en un archivo `.zip` listo para ser consumido de forma nativa por el futuro motor del juego.
* **Internacionalización (i18n):** Interfaz disponible en Español, Inglés y Francés.
* **Totalmente local:** No requiere backend. Todo el procesamiento y empaquetado se hace en el navegador del usuario por motivos de privacidad y rendimiento.

### 🛠️ Tecnologías utilizadas
* **Frontend:** HTML5, CSS3, Vanilla JS.
* **Estilos:** [Tailwind CSS](https://tailwindcss.com/) (Motor CLI/CDN).
* **Librerías:** [q5play](https://q5play.org/) (MIT) para renderizado y [JSZip](https://stuk.github.io/jszip/) (MIT) para empaquetado local.

## 🇬🇧 English

### 📖 About the project
**Yag2Dpg** started in May 2026 as a simple hands-on exercise to teach real programming to 1st-year high school IT students at IES Campanillas. However, the project quickly escalated into the foundation of an actual video game.

Currently, the project is in its early stages, and the first fully functional and public tool is the **Web Level Editor**.

### ✨ Current Features
* **Web Level Editor:** Modern, responsive interface with layer support (Background, Middle, Foreground, Spawn, Goal).
* **ZIP Export:** The editor automatically packages the map into a `.zip` file, ready to be natively consumed by the upcoming game engine.
* **Internationalization (i18n):** Interface available in Spanish, English, and French.
* **Fully Local:** No backend required. All processing and packaging are done securely in the user's browser for privacy and performance.

### 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3, Vanilla JS.
* **Styling:** [Tailwind CSS](https://tailwindcss.com/) (CLI/CDN Engine).
* **Libraries:** [q5play](https://q5play.org/) (MIT) for rendering and [JSZip](https://stuk.github.io/jszip/) (MIT) for local client-side packaging.
