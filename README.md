## 🇪🇸 Español

### 📖 Sobre el proyecto
**YAGCE** comenzó en mayo de 2026 como un simple ejercicio práctico para enseñar a programar a los alumnos de la asignatura TICO de 1º de Bachillerato del IES Campanillas. Sin embargo, el proyecto escaló rápidamente hasta convertirse en la base de un motor para crear y publicar videojuegos reales. Su primer nombre fué **Yag2Dpg** (Yet another generic 2D platformer game), y en su versión 0.0.2 cambió a su nombre actual, junto al cambio de motor, desde q5play a Phaser 4.

Actualmente, el proyecto se encuentra en su fase inicial, centrada en colocar los cimientos del motor, actualmente solo se encuentra disponible el **Editor de Niveles Web**, y un entorno de pruebas de juegos.

### ✨ Características actuales
* **Editor de Niveles Web:** Interfaz moderna y *responsive* con soporte para capas (Fondo, Medio, Frente, Spawn, Meta).
* **Probador de niveles en línea** Interfaz moderna y *responsive* que permite probar de forma muy básica los niveles creados con el editor dentro del motor.
* **Exportación en ZIP:** El editor empaqueta automáticamente el mapa en un archivo `.zip` listo para ser consumido de forma nativa por el motor del juego.
* **Internacionalización (i18n):** Interfaz disponible en Español, Inglés y Francés.
* **Totalmente local:** No requiere backend. Todo el procesamiento y empaquetado se hace en el navegador del usuario por motivos de privacidad y rendimiento.

### 🛠️ Tecnologías utilizadas
* **Frontend:** HTML5, CSS3, Vanilla JS.
* **Estilos:** [Tailwind CSS](https://tailwindcss.com/) (Motor CLI/CDN).
* **Librerías:** [Phaser 4](https://phaser.io/) (MIT) para el motor 2D y renderizado, y [JSZip](https://stuk.github.io/jszip/) (MIT) para empaquetado local.

## 🇬🇧 English

### 📖 About the project
**YAGCE** started in May 2026 as a simple hands-on exercise to teach real programming to 1st-year high school IT students at IES Campanillas. However, the project quickly escalated into the foundation of an engine to create and publish actual video games. Its first name was **Yag2Dpg** (Yet another generic 2D platformer game), and in its version 0.0.2 it changed to its current name, along with the engine switch, from q5play to Phaser 4.

Currently, the project is in its early stages, focused on laying the foundations of the engine; currently, only the **Web Level Editor** and a game testing environment are available.

### ✨ Current Features
* **Web Level Editor:** Modern, responsive interface with layer support (Background, Middle, Foreground, Spawn, Goal).
* **Online level tester:** Modern and responsive interface that allows basic testing of levels created with the editor inside the engine.
* **ZIP Export:** The editor automatically packages the map into a `.zip` file, ready to be natively consumed by the upcoming game engine.
* **Internationalization (i18n):** Interface available in Spanish, English, and French.
* **Fully Local:** No backend required. All processing and packaging are done securely in the user's browser for privacy and performance.

### 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3, Vanilla JS.
* **Styling:** [Tailwind CSS](https://tailwindcss.com/) (CLI/CDN Engine).
* **Libraries:** [Phaser 4](https://phaser.io/) (MIT) for the 2D engine and rendering, and [JSZip](https://stuk.github.io/jszip/) (MIT) for local client-side packaging.
